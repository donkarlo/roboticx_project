# nd_route_finder Android

Native Android companion for `nd_route_finder`.

Features:
- tap map to choose start point;
- Cycling / Hiking mode;
- recursive loading of previous GPX tracks from a selected Android document-tree folder;
- target distance and required maximum slope;
- round-trip candidate generation with BRouter and elevation-aware slope validation;
- previous GPX tracks in gray and generated route in red;
- GPX export through Android's document picker.

The app uses OpenStreetMap tiles for map display and the public BRouter online endpoint for route generation.
